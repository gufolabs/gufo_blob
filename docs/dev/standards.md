# Supported Standards

Gufo Blob implements and is guided by the following standards:

## IETF

* [RFC959][RFC959]: FILE TRANSFER PROTOCOL (FTP)
* [RFC2428][RFC2428]: IPv6 and Extended Operations Support for FTP
* [RFC2463][RFC2463]: FTP Service Extensions Mechanism
* [RFC3659][RFC3659]: Extensions to FTP

## :simple-python: Python PEP

* [PEP8][PEP8]: Style Guide for Python Code
* [PEP561][PEP561]: Distributing and Packaging Type Information
